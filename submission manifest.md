## 5. Reproducibility

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the models:

```bash
python dcf.py
python msft_proforma.py
python comps.py
python project1_reconciliation.py
```

Launch the Streamlit app:

```bash
python -m streamlit run app.py
```
